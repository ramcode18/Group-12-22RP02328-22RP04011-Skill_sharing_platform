A Laravel-based web application that empowers community members to share, request, and Learn skills within their network. Built to promote collaboration and knowledge exchange at a grassroots level.

 Project Overview

The Community Skill Sharing Platform enables users to:

- Register and log in securely  
- Post skills they are willing to share  
- Search for available skills by category or keyword  
- Request help or collaborate with others  
-Comment and interact on skill listings  

This platform fosters local development through peer learning and collaboration.

Technologies Used

- PHP** (Laravel Framework)  
- MySQL (Relational Database)  
- Blade (Laravel templating engine)  
- Tailwind CSS / Bootstrap (Responsive UI styling)  
-Git & GitHub (Version control and collaboration)
